Shettar Business — System Requirements

Desktop and tablet requirements for running the Shettar Business native app.

Scope. This document covers the Shettar Business native application (desktop installers and tablet builds). The browser portal at the Business web URL may work on additional devices, but native features (auto-updates, local printing integrations, and packaged WebView performance) require a supported desktop or tablet build.

ProductShettar Business (com.shettar.business)
PlatformsWindows, macOS, Linux, Android tablets, iPad / iOS
Distributionshettar.com/download and partner rollout channels
Last updated15 September 2026

1. Shared requirements (all platforms)

Internet Stable broadband or LTE/5G connection to Shettar API and update endpoints. Offline use is limited; booking, payouts, and sync require connectivity.
Account Active Shettar Business partner account with portal access.
Display Minimum useful workspace roughly 1280 × 720 (desktop) or tablet width ≥ 600 dp. Landscape is recommended for day-to-day operations.
Storage At least 500 MB free space for the app, WebView runtime, and updates (more recommended on tablets with photo-heavy listings).
Memory 4 GB RAM is sufficient for normal use on PCs and Macs.

2. Desktop — Windows

Operating system Windows 10 (version 1809 or later) or Windows 11. 64-bit (x64) required.
WebView runtime Microsoft Edge WebView2 Runtime (usually preinstalled on Windows 11; installable on Windows 10 if missing).
Installer Shettar Business Windows .exe from the official download page.
Hardware x64 CPU; 4 GB RAM; 500 MB free disk.
Permissions Allow outbound HTTPS to Shettar services; allow the app through local firewall if prompted.

3. Desktop — macOS

Operating system macOS 11 Big Sur or later (Apple Silicon and Intel supported).
WebView System WKWebView (bundled with macOS).
Installer Shettar Business .dmg for Apple Silicon or Intel, matching the Mac architecture.
Hardware Apple Silicon (M-series) or Intel Mac; 4 GB RAM; 500 MB free disk.
Permissions Grant network access when prompted. For Gatekeeper: open from Downloads or System Settings → Privacy & Security if the first launch is blocked.

4. Desktop — Linux

Operating system 64-bit Linux distributions comparable to Ubuntu 22.04+ / Debian-class with desktop environment.
WebView library WebKitGTK 4.1 (libwebkit2gtk-4.1) and related GTK dependencies.
Packages AppImage, .deb, or .rpm from the official download page.
Hardware x64 CPU; 4 GB RAM; 500 MB free disk.

AppImage is the most portable option when distribution packages are unavailable. Install WebKitGTK 4.1 via the distro package manager if the app fails to start.

5. Tablets — Android

Operating system Android 7.0 (API 24) or later. Built against current Android SDK targets used by the release.
Form factor Tablet only. Smallest screen width ≥ 600 dp. Phones are not supported and are excluded from Play Store / side-load targeting.
Orientation Landscape (sensor landscape). Use a tablet stand or dock for front-desk use.
CPU architecture arm64-v8a (64-bit ARM) for production builds.
Installer Shettar Business Android APK / AAB from partner distribution or Play (when published).
Hardware Android tablet with ≥ 600 dp width (e.g. 10″ class); 4 GB RAM; Wi‑Fi or cellular data.
Examples Samsung Galaxy Tab A/S series (10″+), Lenovo Tab, Pixel Tablet, and similar mid/full-size Android tablets meeting the width rule.

6. Tablets — iPad / iOS

Operating system iOS / iPadOS 14.0 or later.
Devices iPad (recommended for operations). The build may also install on supported iPhones, but the Business UI is optimised for tablet and desktop layouts.
Capabilities 64-bit arm64 device with Metal graphics support.
Installer Shettar Business iOS IPA via TestFlight, App Store, or enterprise/partner distribution when enabled.
Hardware iPad (6th generation or newer class recommended); stable Wi‑Fi; adequate free storage for app updates.
Orientation Portrait and landscape supported; landscape preferred for dashboard and listing workflows.

7. Recommended front-desk setup

  • Primary: Windows 10/11 PC or Mac with 4 GB RAM and wired or strong Wi‑Fi.
  • Secondary / roaming: 10″+ Android tablet (landscape) or iPad on the same property Wi‑Fi.
  • Display: External monitor optional on desktop; avoid phone-sized screens for checkout and calendar work.
  • Power: Keep tablets charged or docked during peak check-in/out windows.

8. Unsupported or limited

  • Android phones (width under 600 dp) — not supported by the native Android build.
  • 32-bit only Windows or legacy OS versions below the minima above.
  • ChromeOS / browsers-only kiosks — use the web portal if needed; native desktop/tablet features may be unavailable.

9. Updates

Desktop builds check Shettar update endpoints and may prompt for in-app updates. Keep the app current so WebView security patches and Business portal features stay aligned. Tablet builds update through the same release channel or store listing used for distribution.
